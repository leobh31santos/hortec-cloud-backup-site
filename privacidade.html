Política de Privacidade — HORTEC Cloud Backup

Atualização: 20 de novembro de 2026.

1. Finalidade

O HORTEC Cloud Backup é destinado à geração e ao armazenamento remoto de cópias de segurança de bancos de dados utilizados pelo sistema HORTEC, para auxiliar a recuperação de dados em caso de falha ou desastre.

2. Informações tratadas

Os arquivos de backup podem conter dados comerciais e pessoais registrados pelos usuários dos bancos SQL Server, conforme o conteúdo de cada instalação. A integração Google Drive poderá tratar metadados de arquivos e pastas, como nomes, tamanhos, identificadores e datas necessários ao gerenciamento dos backups.

3. Acesso ao Google Drive

A integração planejada utiliza autorização OAuth de uma conta Google Drive administrada centralmente pelo responsável pelo HORTEC. A autorização é usada para criar pastas, transferir, consultar, substituir e remover arquivos de backup relacionados ao serviço. O acesso solicitado à API do Google Drive poderá abranger todos os arquivos da conta autorizada. A aplicação não utiliza esse acesso para publicidade ou venda de dados.

4. Armazenamento e compartilhamento

Os backups enviados serão armazenados no Google Drive autorizado, sujeito às políticas e medidas de segurança do Google. Os dados não se destinam à divulgação pública. O operador do serviço poderá ter acesso administrativo aos arquivos. Não há previsão de venda ou compartilhamento de dados para publicidade.

5. Segurança

O projeto prevê medidas de proteção de acesso e criptografia de arquivos na implementação definitiva. Como o envio para a nuvem ainda está em desenvolvimento, não declaramos que esses controles já estejam implantados em produção. Credenciais e tokens devem ser mantidos em armazenamento protegido e não devem ser publicados.

6. Retenção e exclusão

A política projetada prevê uma cópia remota ativa por banco de dados, com substituição após confirmação do novo envio. A frequência, o prazo de retenção e a exclusão definitiva serão confirmados antes da implantação em produção. Cópias locais são geridas separadamente.

7. Direitos e solicitações

Solicitações sobre acesso, correção, exclusão e tratamento de dados devem ser encaminhadas ao responsável pelo sistema, observadas as obrigações legais e contratuais aplicáveis.
