HORTEC Cloud Backup

O HORTEC Cloud Backup é um módulo do sistema HORTEC destinado a gerar e transferir cópias de segurança de bancos de dados Microsoft SQL Server para armazenamento remoto, visando à recuperação após perda ou falha do computador.

Como funciona

O módulo identifica o banco de dados configurado na instalação, gera uma cópia de segurança local e, após configuração e autorização do administrador, poderá enviar o arquivo para uma conta Google Drive centralizada. O módulo está em desenvolvimento; o envio automático para o Google Drive ainda não foi disponibilizado em produção.

Uso de dados Google

A integração planejada utiliza a API do Google Drive para criar pastas, enviar, verificar e gerenciar arquivos de backup na conta autorizada pelo administrador. Os clientes finais do HORTEC não precisam autenticar suas próprias contas Google.
